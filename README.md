# Leonida · carte interactive GTA VI

Carte personnelle de l'État de Leonida (Grand Theft Auto VI).

- Fond de carte : tuiles « day » de [gtadb.org](https://map.gtadb.org) et contributeurs, licence CC BY 4.0 (voir `tuiles/LICENSE-DATA-gtadb.txt`).
- Points d'intérêt : données Map Genie, converties dans les coordonnées de la carte.
- Affichage : [OpenLayers](https://openlayers.org) (licence BSD 2-Clause, voir `lib/LICENSE-openlayers.md`).
